# Personal Journal Manager

## Project Description

Personal Journal Manager is a simple Python-based application that allows users to maintain their personal journal digitally. The program uses file handling and exception handling concepts of Python to create, store, view, search, and delete journal entries.

## Features

* Create a journal file automatically.
* Add new journal entries.
* View all saved journal entries.
* Search for a particular entry using keywords.
* Delete all journal entries when required.
* Handle common file-related errors using exception handling.

## Technologies Used

* Python 3
* File Handling
* Exception Handling
* Object-Oriented Programming (OOP)
* OS Module

## File Structure

* `journal.txt` – Stores all the journal entries.
* `journal_manager.py` – Main Python program containing the Journal Manager class and menu system.

## How to Run the Project

1. Make sure Python 3 is installed on your computer.
2. Save the program as `journal_manager.py`.
3. Open a terminal or command prompt.
4. Navigate to the project folder.
5. Run the following command:

```
python journal_manager.py
```

## Menu Options

1. Add a new journal entry.
2. View all journal entries.
3. Search for a journal entry using a keyword.
4. Delete all journal entries.
5. Exit the application.
